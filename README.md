Что это такое

Aegis Cleaner — программка с чёрным интерфейсом, которая показывает все процессы на компьютере, даёт их завершить и порулить автозагрузкой. Ещё она сканирует файлы на подозрительные, следит за папками TEMP и Downloads в реальном времени и, если что-то находит, кидает это в карантин. Плюс есть проверка файлов через VirusTotal.

Важно понимать: это не замена Windows Defender. Настоящий антивирус я ещё не умею писать — просто учусь. Если нужна реальная защита, поставьте нормальный AV.

Как запустить

Скачайте AegisSetup.exe из раздела Releases и запустите. Он поставит программу, спросит про автозагрузку и сделает ярлык. Удаляется тем же установщиком.

Если хотите запустить из исходников — нужен Python 3.11 и выше. Ставите библиотеки командой pip install psutil watchdog requests, потом запускаете python aegis.py.

Про VirusTotal

Чтобы проверять файлы через VirusTotal, нужен бесплатный API-ключ. Взять можно на virustotal.com в разделе профиля. В программе: Настройки, вставить ключ, сохранить. Бесплатно дают 4 запроса в минуту и 500 в сутки, этого хватит.

Чего программа не умеет

Чтобы вы не ждали от неё лишнего — она не заменяет Windows Defender, не ловит файлы до того как они запишутся на диск, не ищет по базам сигнатур, не сканирует архивы и не прячет себя от других программ. Всё это требует драйверов и подписей, которых у меня пока нет. Может, когда-нибудь добавлю, если разберусь.
